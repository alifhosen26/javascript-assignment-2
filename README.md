# JavaScript Assignment 2 🚀

This repository contains my **JavaScript Assignment 2**, focused on strengthening my programming fundamentals through function-based problem solving, validation, calculations, and debugging.

## 📌 Assignment Overview

In this assignment, I practiced writing JavaScript functions and solving different real-world programming problems.

### 🧩 Problems Included

1. **Match Winner**

   * Determines the winner between Team A and Team B based on their goals.
   * Handles invalid input.

2. **Elevator Weight Safety Checker**

   * Calculates the total weight of passengers.
   * Checks whether the total weight is within the safe limit.

3. **AI Token Cost Calculator**

   * Calculates the cost based on the number of AI tokens used.
   * Includes input validation and additional token calculations.

4. **Top Rated Restaurant Finder**

   * Finds the highest-rated restaurant from a list of restaurants.

5. **API Response Time Monitor**

   * Calculates the average API response time.
   * Includes debugging and error handling.
